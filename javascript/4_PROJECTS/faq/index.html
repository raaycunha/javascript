FAQ

JavaScript é uma linguagem de programação que adiciona dinamismo, inteligência e interatividade a páginas web. Enquanto o HTML define a estrutura de um site e o CSS cuida da aparência (estilo), o JavaScript é responsável pelo comportamento e pelas ações, como animações, pop-ups e atualização de conteúdos em tempo real.

A principal diferença está no escopo (onde a variável pode ser acessada) e na reatribuição. O var é o método antigo e pode ser acessado em toda a função/globalmente, permitindo redeclarações. O let respeita blocos de código (como chaves {}) e é mais seguro.

Em JavaScript, uma função de callback é simplesmente uma função que é passada para outra função como um argumento. Essa função recebida como argumento é executada (ou "chamada de volta") pela função principal, geralmente após a conclusão de uma determinada tarefa.
